## Шаг 1: Создание базы данных

### Вариант А: MySQL Workbench
1. Откройте MySQL Workbench
2. Подключитесь к серверу MySQL
3. Откройте файл `full_database_script.sql`
4. Нажмите кнопку "Execute" (молния) или Ctrl+Shift+Enter
5. База данных `furniture_company` будет создана со всеми данными

### Вариант Б: Командная строка MySQL
```bash
mysql -u root -p < full_database_script.sql
```

### Вариант В: phpMyAdmin
1. Войдите в phpMyAdmin
2. Создайте новую базу данных `furniture_company`
3. Выберите базу данных
4. Перейдите на вкладку "SQL"
5. Скопируйте содержимое файла `full_database_script.sql`
6. Вставьте и выполните

## Шаг 2: Проверка данных

После импорта выполните проверочные запросы:

```sql
-- Проверка количества записей
SELECT 'Material_types' as table_name, COUNT(*) as count FROM Material_types
UNION ALL
SELECT 'Product_types', COUNT(*) FROM Product_types
UNION ALL
SELECT 'Workshops', COUNT(*) FROM Workshops
UNION ALL
SELECT 'Products', COUNT(*) FROM Products
UNION ALL
SELECT 'Product_workshops', COUNT(*) FROM Product_workshops;

-- Должно быть:
-- Material_types: 4
-- Product_types: 6
-- Workshops: 12
-- Products: 20
-- Product_workshops: 130
```

## Шаг 3: Создание ER-диаграммы в PDF

### Способ 1: Через браузер (самый простой)
1. Откройте файл `ER_diagram.html` в браузере (Chrome, Firefox, Edge)
2. Нажмите Ctrl+P (Print)
3. Выберите "Сохранить как PDF"
4. Сохраните файл как `ER_diagram.pdf`

### Способ 2: Через PlantUML (если установлен)
```bash
# Установите PlantUML
# Скачайте с https://plantuml.com/ru/download

# Генерация PDF
java -jar plantuml.jar ER_diagram.puml
```

### Способ 3: Онлайн PlantUML
1. Откройте https://www.plantuml.com/plantuml/
2. Скопируйте содержимое файла `ER_diagram.puml`
3. Вставьте в редактор
4. Скачайте результат как PDF

### Способ 4: Через Python (wkhtmltopdf)
```bash
# Установите wkhtmltopdf
# Windows: https://wkhtmltopdf.org/downloads.html

# Конвертация
wkhtmltopdf ER_diagram.html ER_diagram.pdf
```

## Шаг 4: Примеры использования

### Просмотр списка продукции
```sql
SELECT * FROM v_products_full;
```

### Просмотр списка цехов
```sql
SELECT 
    workshop_id,
    workshop_name,
    workshop_type,
    staff_count,
    is_active
FROM Workshops
WHERE is_active = TRUE
ORDER BY workshop_type, workshop_name;
```

### Добавление новой продукции
```sql
INSERT INTO Products (
    product_name, 
    article_number, 
    product_type_id, 
    material_type_id, 
    min_partner_price
)
VALUES (
    'Новый шкаф Дуб светлый', 
    '9999999', 
    (SELECT product_type_id FROM Product_types WHERE product_type_name = 'Шкафы'),
    (SELECT material_type_id FROM Material_types WHERE material_type_name = 'Фанера'),
    55000
);
```

### Редактирование продукции
```sql
UPDATE Products 
SET 
    min_partner_price = 60000,
    is_available = TRUE
WHERE article_number = '9999999';
```

### Просмотр продукции с цехами
```sql
SELECT 
    p.product_name,
    p.article_number,
    w.workshop_name,
    w.workshop_type,
    pw.production_time_hours
FROM Products p
JOIN Product_workshops pw ON p.product_id = pw.product_id
JOIN Workshops w ON pw.workshop_id = w.workshop_id
WHERE p.article_number = '1549922'
ORDER BY pw.production_time_hours;
```
