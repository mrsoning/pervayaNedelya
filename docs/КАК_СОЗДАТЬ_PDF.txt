=============================================
КАК СОЗДАТЬ PDF ИЗ ER-ДИАГРАММЫ
=============================================

Файл ER-диаграммы: diagrams/ER_diagram.html
Целевой PDF:        diagrams/ER_diagram.pdf

---------------------------------------------
СПОСОБ 1: ЧЕРЕЗ БРАУЗЕР (РЕКОМЕНДУЕТСЯ)
---------------------------------------------

1. Откройте файл diagrams/ER_diagram.html в браузере
   (Chrome, Firefox, Edge — двойной клик по файлу
   или перетащите файл в окно браузера).

2. Нажмите Ctrl+P (или Cmd+P на Mac)
   — откроется окно печати.

3. В пункте «Назначение» / «Принтер» выберите
   «Сохранить как PDF» / «Save as PDF».

4. Настройки:
   — Ориентация: Книжная (Portrait)
   — Масштаб: «По размеру» / «Fit to page»
   — Поля: по возможности минимальные (около 1 см)

5. Нажмите «Сохранить» и укажите путь:
   diagrams/ER_diagram.pdf
   (или сохраните в папку diagrams с именем ER_diagram.pdf).

Готово. Файл ER_diagram.pdf создан.

---------------------------------------------
СПОСОБ 2: ЧЕРЕЗ СКРИПТ PYTHON
---------------------------------------------

Установите WeasyPrint:
   pip install weasyprint

Из корня проекта выполните:
   python scripts/generate_pdf.py

Скрипт создаст diagrams/ER_diagram.pdf из
diagrams/ER_diagram.html.

---------------------------------------------
СПОСОБ 3: WKHTMLTOPDF (ЕСЛИ УСТАНОВЛЕН)
---------------------------------------------

Из корня проекта:
   wkhtmltopdf diagrams/ER_diagram.html diagrams/ER_diagram.pdf

---------------------------------------------
ПРОВЕРКА
---------------------------------------------

• Откройте ER_diagram.pdf в любой программе просмотра PDF.
• Убедитесь, что видны все 5 таблиц, связи, ключи (ПК, ВК) и легенда.
